
This tool can be used to minimize Least significant bit steganography detection by distributing the payload across 
multiple images as opposed to 1-1 payload-image which is limited in CARRIER capacity as a higher payload becomes easily 
detectable.

The tool implements Hashing to verify payload file integrity, Scikit for image processing, Tkinter for GUI and 
Matplot-lib for the report module.

The motivation for this project was both to expand and showcase knowledge in Software engineering and cybersecurity 
through the application of programming, algorithm design and Steganography concepts.
